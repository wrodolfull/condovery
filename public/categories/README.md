# Imagens de categorias do Elevadoor

Pack com 23 imagens WebP 256x256, incluídas as categorias padrão e opcionais.

As categorias são definidas no banco e são mapeadas por nome/ícone em `src/lib/artwork.ts`; o aplicativo usa os mesmos arquivos em `/categories`. Se uma categoria não tiver arte ou a requisição de imagem falhar, o componente mantém o ícone Lucide. Os arquivos têm fundo transparente fora dos círculos.

As categorias Moda, Presentes, Saúde, Eletrônicos, Outros e Desapego usam ilustrações enquanto as demais têm imagens fotográficas.
